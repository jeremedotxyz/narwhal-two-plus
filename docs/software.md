# Software reference and operating guide

Version 0.1.0 requires Python >=3.10. Runtime uses only the standard library. Commands below run from the repository root with `PYTHONPATH=src`. Alternatively install with `python3 -m pip install -e .` inside a virtual environment and replace `python3 -m narwhal` with `narwhal`.

## Modules and execution path

| Module | Responsibility |
|---|---|
| `config.py` | Strict dataclass configuration, supported version and finite parameter checks |
| `physics.py` | Path length, bistatic inversion, Snell helper and analytical metrics |
| `pipeline.py` | Raw-event reconstruction, invalid-return policy, seeded plane simulator |
| `protocol.py` | 40-byte codec, NWP1 framing, point validity and CRC checks |
| `cli.py` | Simulation, replay, bounded UDP receive and file export |
| `__main__.py` | Module entry point |

There are no component drivers or embedded firmware. All coordinates are sensor-frame coordinates. Multi-line scans repeat a stationary target; line IDs distinguish acquisition cycles but do not supply a pose estimate.

## Configuration

`config/concept.json` is the versioned default calibration/assumption set. Unknown keys fail at load time. Physical values must be finite. Range gates must exceed the baseline; scan field must be positive and below 90 degrees; at least two samples are required; timing noise and attenuation must be nonnegative.

`n_group` determines path speed, while `n_phase` is used by the standalone refraction helper. Temperature and salinity are retained for provenance but do not update either index. `source_delay_ns` is a constant subtracted during reconstruction; a real instrument needs calibrated per-channel, per-angle and thermal delays rather than this sole parameter. `calibration_id` must be nonempty.

## Generate and reconstruct

```bash
PYTHONPATH=src python3 -m narwhal --config config/concept.json simulate --out runs/demo --lines 2 --plane-m 5 --seed 532
```

The synthetic raw file stores one event per transmitted shot. Intensity is an arbitrary attenuated count. Dropout is independent of intensity. A no-return event uses JSON `null` for `tof_ns`. Gaussian timing jitter is applied to the path delay; no waveform or ADC sample stream is generated.

Files written for `--out runs/demo`:

| File | Purpose |
|---|---|
| `demo.raw.jsonl` | Synthetic raw events; only generated by simulation |
| `demo.jsonl` | Reconstructed points, one per event |
| `demo.csv` | Same point fields in tabular form; invalid coordinates blank |
| `demo.ply` | Valid XYZ points and intensity; invalid returns omitted |
| `demo.metadata.json` | Configuration, provenance and record counts |

Existing output files with the same prefix are overwritten. Choose a distinct run prefix when retaining experimental data. Output is currently buffered in memory; this tool is intended for bounded captures, not continuous deployment logging.

## Raw-event input contract

```json
{"schema_version":1,"timestamp_ns":0,"time_basis":"SIM_RELATIVE","simulated":true,"line_id":0,"angle_rad":0.0,"tof_ns":44.6992,"intensity":900}
```

Every event must explicitly identify whether it is simulated. Angle is the calibrated water-side angle in radians, inside the configured field. `tof_ns` is an already estimated delay including the source delay removed by configuration. Timestamp is uint64; line ID is uint32; intensity is uint16. No-return delay is `null`. Nonphysical numeric delay is flagged invalid; malformed schema, invalid integer ranges and out-of-field angles stop replay.

`time_basis` equal to `TAI` asserts synchronization; other labels set UNSYNCED. The tools do not verify the source's clock assertion. Real data must be captured with independently verified clock quality and provenance. The proposed synchronized epoch is 1970-01-01 00:00:00 TAI, not Unix UTC or GPS time.

```bash
PYTHONPATH=src python3 -m narwhal --config config/concept.json replay examples/synthetic-sample.raw.jsonl --out runs/sample
```

Replay performs reconstruction; it does not estimate ToF from ADC waveforms. It preserves synthetic and synchronization flags from the input. JSON exports use `null` for invalid floating-point values so the files remain standards-compliant JSON.

## Proposed packet capture

```bash
PYTHONPATH=src python3 -m narwhal receive --host 127.0.0.1 --port 53200 --packets 2 --timeout 5 --out runs/capture
```

The receive command listens for [NWP1 packets](protocol.md). It never sends a control message. Default bind is loopback. Deliberately choose an interface address only on a trusted integration network; the protocol has no authentication or encryption, and CRC is not authentication. Arrival order is preserved; sequence IDs and peers are recorded, but gaps, duplicate packets and sender identity are not resolved. Malformed packets and timeout end capture with exit code 2. Export occurs after the requested packet count; an interrupted capture does not create a partial dataset.

Metadata configuration for a received point packet is the host's supplied context, not a verified sender calibration. NWP1 lacks an embedded calibration ID. An integration must negotiate and verify that ID through a separate authenticated session protocol before treating data as calibrated.

## Programmatic codec example

```python
from narwhal.pipeline import Point, SIMULATED, UNSYNCED
from narwhal.protocol import encode_packet, decode_packet
p = Point(0, 0.0, -0.03, 5.0, 5.0, 900, 0.0, 0, SIMULATED | UNSYNCED)
wire = encode_packet(0, [p])
sequence, recovered_points = decode_packet(wire)
assert sequence == 0
```

## Tests, reproducibility and error handling

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 examples/reproduce.py
```

The test suite includes an actual localhost UDP socket. A sandbox that blocks local socket binding must explicitly permit that test or run it on an ordinary local environment. Tests do not access an external host. CLI success is exit code 0, operational/validation failure is 2. Argparse also uses 2 for command syntax errors.

## Drawing regeneration

Optional document dependencies are listed in `hardware/source/requirements.txt`. With those installed:

```bash
python3 hardware/source/generate_blueprint.py
```

This rewrites the three-sheet PDF and standalone sensor-data PDF. The PNG preview is a separately rendered snapshot. Use Poppler's `pdftoppm` to refresh it and visually inspect every sheet after geometry or layout edits. Original procedural dimensions are drawing coordinates with explicit dimension labels; there is no 3D CAD solid or machining export.
